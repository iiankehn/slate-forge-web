# Published writing, sharing and office compatibility release

Published November 11, 2026 at https://slate-web.iiankehn.com/ . Runtime source: `994a2ae0e1859939ed9d013ce89128485847a055`, merged through [PR #28](https://github.com/iiankehn/slate-forge-web/pull/28). ## Included

- Writing-scoped Select All; keyboard/right-click context menu; original, merged-formatting and text-only paste; guarded Cut/Copy; review-safe Clear formatting; File labeling; independent compact/collapsed ribbon preferences and shared labeled commands.
- Fresh editable redacted DOCX/ODT/HTML copies with logical text/object removal, regenerated visible assets, private metadata/history removal and preserved unmarked editable content. Originals, history and backups remain intact. Flattened PDF redaction remains separate.
- Bounded heterogeneous opaque ODF groups, repaired occupied path frames, explicit-unit rigid/reflected non-text leaf matrices, and nested native ODT/DOCX groups through eight levels.
- Bounded whole-paragraph ODT revisions with safe anchors, paragraph design, app Accept/Reject/Undo, and strict refusals for unsupported structures. Actual-editor failed and corrected fixtures remain documented.

## Retained limits

This publishes the implemented batch, not the entire compatibility inventory. Native ODF group compositing, mirrored/skewed text, broader affine/paint cases, nested/object/row/boundary revisions, unanchored whole-document replacements and other listed cases remain explicitly unsupported. Standard ODF formatting metadata cannot supply missing prior values for faithful Reject. See [COMPATIBILITY_INVENTORY.md](COMPATIBILITY_INVENTORY.md).

Actual Writer resaves are bounded exchange evidence; Writer's interactive review commands and Microsoft Word rendering are not certified. Physical-device testing was excluded by the user. Storage/database/backup identifiers, existing public/private origins, local-first behavior, fonts and the confirmed mobile safe-area fix are preserved. No sub-agents were used for the final implementation/release. Later documentation bookkeeping changes do not rebuild or replace this runtime artifact.
