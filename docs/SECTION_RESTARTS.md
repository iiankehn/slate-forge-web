# Section page-number restarts

Status: published through PR #43 and the PR #44 readiness repair, runtime `cc64a5bd9c2a805631fc55aa570e11cc66e1c903`. [Release evidence](RELEASE_2026_11_17_SECTION_RESTARTS.md) records successful PR/main checks, Pages 44016060269, exact artifact 14297719448 and live verification.

A section may set optional integer `pageStart` from 1 to 9999. Blank continues counting; a restart is an event at the start of a top-level section on a new page. It is not inherited furniture. Hidden pages advance the same counter: an opening 1, hidden restart at 7 and visible continuation produce 1 / hidden / 8. Physical preview labels remain Page 1 / Page 2 / Page 3. A first section can start at 7 without adding a blank opening page. Counting continues after section scope ends.

The insert panel forces a new page when a start is entered and rejects invalid numeric input. Continuous editing retains the section attribute. Native ODT emits `style:page-number` on the first bound paragraph/table; Word emits `w:pgNumType/@w:start`. Native imports use current values, including the first Word section. Raw direct-body ODT paragraph/heading/table runs can carry a bounded decimal restart at a master assignment or explicit page break. Consumed native breaks do not become duplicate page-break nodes. Restart-only changes must create a section even when page geometry stays unchanged.

Nested or continuous restart models refuse native export and measured preview. Unsupported native values, numbering styles, nested raw assignments, complex furniture/history and unsupported geometry retain explicit warned fallbacks. Sequential DOCX remains refused. Older builds can ignore this optional attribute; no database, backup envelope, session key, origin or hosting identity changes are introduced. Originals, retained review and backups remain intact.

Authored verification includes strict input/HTML handling, repeated ODT and Word native round trips, first-section behavior, nested/continuous refusals, backup/sharing preservation, physical preview labels, hidden counting and an empty pending preview page. The browser scenario downloads both native formats and saves/reloads them. Independent raw XML Office controls set a hidden middle-page restart at 7; ODT raw/normalized/resaved rendering must match strictly, and Word generated/resaved rendering must match strictly. Both require footer values 1 / hidden / 8 and current native restart values. These acceptance requirements passed in the repaired diagnostic run below; they do not establish Microsoft Word or physical-device certification.
