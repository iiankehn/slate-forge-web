# Section paper and margin release — November 15, 2026

PR [#41](https://github.com/iiankehn/slate-forge-web/pull/41) adds optional A4/Letter paper and 15/22/30 mm uniform margins to writing sections. Legacy sections keep inheritance. Native ODT masters, document-level Word, measured preview, saving, sanitized HTML, backups and sharing carry supported current values. ODT nested sections restore parent geometry; nested Word geometry explicitly refuses output. Images/canvases fit active content dimensions and columns. Compact Word header/footer distances fit inside 15 mm margins.

Source `f5f0960ffaa450f7fe57c09b4986f9d1e4ed7a96` passed 758 Node regressions, 20 tooling-policy checks and ten actual LibreOffice 24.2.7.2 probes in PR [CI 43757442567](https://github.com/iiankehn/slate-forge-web/actions/runs/43757442567). All 270 browser cases passed across five profiles without flaky results. GitHub verified all 56 live shell/worker URLs against the artifact and reconciled worker cache `0b3fcca8b8e92f8e` on the first publication check. All tests, builds, browsers, editor conversions and live-byte/cache checks belong to GitHub. No local suite or probe ran.

The two new Office cases independently transform the committed raw orientation seed into A4/22 → Letter landscape/15 → A4/22 without using the importer/exporter under test. Raw transformed and normalized ODT XML validate against core ODF 1.3. ODT raw/normalized/actual-resaved renders are pixel-identical at 144 DPI. The Word case uses generated DOCX as its explicit reference against the actual Word resave, without a cross-format ODT pixel claim. Both retain current native paper/margins and three page orientations. Prior eight probes retain their checks.

Initial GitHub checks passed all ten exchanges but exposed an asymmetric-margin parser bug: a 30 mm left override plus 15 mm shorthand was incorrectly treated as uniform 30 mm. Missing sides now resolve against the shorthand instead of the selected left value, so unsupported asymmetric geometry cannot enter the supported projection. A page-image assertion was corrected to follow the existing placement contract: preserve x=205 mm and shrink width to the Letter-specific 10.9 mm edge remainder. Native placement behavior and strict render checks were not relaxed. See [SECTION_PAPER_GEOMETRY.md](SECTION_PAPER_GEOMETRY.md).

Arbitrary paper, asymmetric/custom margins, numbering restarts, complex furniture/history and nested Word geometry remain explicit limits. Older builds may ignore optional overrides; HTML/backups retain full intent. Backup envelopes, database/session identifiers, public origin, private Site, originals, body font choices and mobile safe areas are preserved. No universal Word or physical-device certification is claimed. Broader cases remain in [COMPATIBILITY_INVENTORY.md](COMPATIBILITY_INVENTORY.md).
