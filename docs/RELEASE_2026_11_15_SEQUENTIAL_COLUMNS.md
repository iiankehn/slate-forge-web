# Sequential column-flow release — November 15, 2026

PR [#38](https://github.com/iiankehn/slate-forge-web/pull/38) adds top-to-bottom page-column flow for top-level writing text, headings and lists. The explicit mode is available in Section tools, retained by saving, editable HTML, workspace backups and editable sharing, and represented in native ODT. Compatible 2 → 3 → 2 page-master columns now use this mode instead of the earlier balanced projection. Editing remains continuous; Page preview supplies the measured paper layout.

This repairs the bounded representation; the old failed balanced-column fixture stays a recorded failure.
