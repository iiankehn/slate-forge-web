## Review and interoperability boundary

Fresh unchanged ODT copies restore the sanitized full existing review tree, supported layout and recording setting. Existing Accept/Reject and Undo/Redo controls operate on it. Native content is an editable accepted projection with recording off. A package SHA-256 binding prevents automatic stale restoration after external edits; it is not authentication. Missing, invalid, unsafe or unrepresentable history falls back to current native content. The separate editable-redaction export does not attach retained history.
