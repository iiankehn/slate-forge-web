## Actual group exchange evidence

The existing scratch probe was executed once by Adversarial in LibreOfficeDev `26.8.0.0.alpha0` (`2c87e51eeaa2b413ff4ae097b2705eea1995d8e5`). Input: `docs/fixtures/odt-opaque-shape-group-input.odt`; resave: `test/fixtures/odt-opaque-shape-groups-libreoffice-resaved.odt`. The group gains only a name/style with decorative/run-through metadata, with no group transform or paint effect. Maximum measured geometry delta was .0146044 mm (.08215 logical canvas units); the initial .01 mm diagnostic target was exceeded and is not reported as a pass. The existing .7-unit native tolerance governs the regression. This is one actual headless editor exchange, not Word/GUI/device certification.

## Resumed heterogeneous corpus and representation repair

The first heterogeneous actual-editor input retained object order, text and exact PNG/JPEG bytes but failed geometry: Writer removed raw nested group translate/rotate attributes without applying them, and rebased an inset polyline while retaining its old origin (about 14 canvas units upward). These are failures, not rounding passes. Raw group transform import remains refused. The repair emits occupied path frames with adjusted origins/vertices; horizontal/vertical sampled paths use round-cap native lines and reopen as editable paths. A corrected actual-editor corpus uses baked child positions/rotations while retaining ordinary group membership and the original inset path. The corrected corpus passes: max child geometry delta .11149 logical units (< existing .7 tolerance), source path/axis vertices <=.00730799 mm, round caps preserved. See [ODT_HETEROGENEOUS_GROUPS.md](ODT_HETEROGENEOUS_GROUPS.md); browser/release evidence is recorded in RELEASE_2026_11_11.md.
